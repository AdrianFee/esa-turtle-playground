Pip: design sheet

Placeholder name. Same shapes everywhere: one module (js/pip.js) draws the canvas sprite and the header, banner and stamp SVGs. Nothing is wired into the app yet.

1. Header mascot, four states

Seen from above, facing right like the turtle on the canvas. Idle blinks now and then (in 4b). Running bobs. Oops is puzzled: wide eyes looking sideways, one brow up, a small "o" mouth and a question mark. Never sad, never cross. Happy is closed smiling eyes and a wide smile, one bounce.

in the header at 40px

2. Canvas sprite, actual size on white

Drawn exactly as the canvas will draw it (sprite scale 1.35 at this screen's pixel ratio). Shell = fill colour, shell outline = pen colour, head/legs/tail always Pip-green with an ink outline and a pale halo. Each pair is shown at actual size and at 4× for inspection.

4. Passport stamp

Empty: a dashed ring with the lesson number. Stamped: a sun-yellow disc with a green ring and Pip's footprint. Challenges are rounded squares. At header size (10px, 8px at narrow widths) the stamped one reads as a green-ringed yellow dot, the empty one as a grey ring.
