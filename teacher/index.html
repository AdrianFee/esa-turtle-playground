🐢 Teacher notes

← Back to the playground

What the playground is. Real CPython running in the browser (via Pyodide) with a drop-in turtle module that draws on a canvas. Nothing is installed and no data leaves the machine. Students' code is saved in their browser's local storage per lesson, so they should use the same computer and browser to pick up where they left off, or use Copy link / Download .py to carry work around.

Differences from Thonny. input() and textinput() are not supported (a friendly message says so). Keyboard and mouse events (onkey, onclick) are accepted but do nothing. Everything else that students at this level use behaves the same, and the Download .py button adds done() so the file runs in Thonny.

Error messages. Python errors are translated into plain English with the offending line highlighted. The original Python error is always available under "Python's own words", so students still learn the real names (SyntaxError, NameError, IndentationError).

Completion checks. Each lesson has light-touch checks (listed below) that look at the code and at what was drawn. They are deliberately generous: the point is encouragement, not grading. Passing a check shows a Next button and marks the lesson with a tick.

Adding lessons. Edit js/lessons.js. Each lesson is a small object with starter code, hints, a solution and checks; the comment at the top of the file lists the check types.
